# Buildy — GitHub partnership brief

## The proposition

Buildy is a BStudioB Ltd desktop-first editor for GitHub Pages. It keeps the user's
HTML/CSS/JavaScript project in GitHub while adding guided navigation, visual editing,
preview, diff review and optional authenticated collaboration. It is intended to make
GitHub Pages more approachable for beginners, educators, designers and solo makers.

## Why this could be relevant to GitHub

- It helps more people successfully publish and maintain GitHub Pages projects.
- It preserves GitHub as the source of truth rather than replacing it with a proprietary CMS.
- It could become a safer, more accessible onboarding layer for static-site creators.
- A future GitHub App could use narrowly scoped repository permissions and explicit user consent.

## Honest current state

- BStudioB Ltd is incorporated in the UK.
- Buildy is an early product with a working Electron/local-server codebase and a private
  authenticated hosted beta.
- It is not currently a GitHub App or a verified Marketplace listing.
- The proposed initial price is a one-time £5 early-access licence, subject to validation.
- There is no claim of GitHub endorsement, partnership, acquisition interest or official status.

## Recommended route

1. Apply to the **GitHub Technology Partner Program** and request an exploratory product/
   integration conversation.
2. Ask whether a GitHub App, Marketplace listing, Education partnership or another route
   best fits Buildy's use case.
3. Only pursue Marketplace billing after Buildy has a real cloud integration and evidence of
   demand. GitHub's published paid-app requirements include an organisation-owned verified
   publisher, minimum installation/user thresholds, monthly and annual plans, and Marketplace
   billing-event handling.

## Evidence to attach

- one-page product brief and 90-second demo;
- screenshots of visual mode, code mode, preview and repository navigation;
- security model: least-privilege permissions, token handling, no unauthorised access;
- customer evidence from interviews and paid pilot tests;
- proposed integration architecture and support/privacy URLs;
- BStudioB Ltd company and contact details.
