GitHub Pages, without the Git busywork

Edit your site. Preview it. Open a review PR.

GhP WebEditor is a desktop and local-server workspace for making real website changes, with a safe GitHub App sign-in and a pull request before anything goes live.

A calmer publishing flow

From idea to review in three steps.

  1. 1

    Connect securely

    Sign in through the GitHub App and approve only the repositories you own or manage.

  2. 2

    Edit with confidence

    Use code or visual editing, import a ZIP, and preview the site before sharing a change.

  3. 3

    Create a review PR

    The editor creates a dedicated review branch and pull request in your repository. You decide when to merge.
