Privacy notice

Buildy processes only the information needed to provide the editor and manage an account.

What we process

When you connect GitHub, Buildy receives an OAuth token and basic account identity so it can access repositories you authorise. We use session storage, error logs and Marketplace billing events to operate the service. If Marketplace billing is enabled, purchase records are stored in the configured Supabase service database. We do not sell personal data.

Desktop mode

The downloaded desktop application can also use a personal access token stored locally by the user. Hosted mode uses GitHub App OAuth instead; tokens are encrypted in the hosted session and are not written to the repository.

Control and contact

You can disconnect GitHub or request deletion by contacting hello@bstudiob.co.uk. BStudioB Ltd is the controller for this service.
